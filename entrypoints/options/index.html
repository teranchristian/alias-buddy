Sync & backup

AliasBuddy uses this browser's built-in extension sync storage when available, while keeping a local copy on this device.

Browser sync stays inside the same browser family: Chrome/Chromium, Edge, and Firefox use separate sync ecosystems. It is not an uninstall-safe long-term backup. Export a JSON backup and keep it somewhere private if you want a durable or cross-browser copy.
